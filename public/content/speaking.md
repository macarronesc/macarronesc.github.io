# Technical speaking — Making cloud research practical

**My role:** Speaker · **Focus:** Distributed Python, serverless computing and scientific data

I share the engineering lessons behind my research: how to run parallel Python across different environments, and how to access scientific data without unnecessary preprocessing. My aim is to connect architectural ideas with tools developers can use.

## PyConES 2025 · Sevilla, Spain

**Talk:** *Multi-Cloud Serverless Parallel Programming in Python (Lithops)*

[Official speaker profile and session](https://pretalx.com/pycones-2025/speaker/TVZK37/)

The session introduced Lithops as a programming model for parallel workloads across cloud providers and infrastructure types. Topics included backend abstraction, task distribution and practical use of serverless Python without rewriting the application around a single provider's APIs.

## EuroSciPy 2025 · Kraków, Poland

**Talk:** *Processing Cloud-Optimized Data in Python (Dataplug)*

[Official speaker profile and session](https://pretalx.com/euroscipy-2025/speaker/TVZK37/)

The session explored access to scientific datasets in object storage: cloud-optimized formats, partitioning and byte-range access, and Dataplug's approach to preparing data for parallel analysis. The emphasis was on the data-access problem behind distributed workloads, not only the compute layer.
